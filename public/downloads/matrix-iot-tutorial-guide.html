Matrix-IoT Hands-On Integration Tutorial

Target Audience: Engineering Students, Lab Instructors, System Engineers | matrix-iot.com
💡 Tutorial Objective
By completing this tutorial, you will configure an ESP32 micro-controller with an RFID scanner, connect it to the Matrix-IoT Gateway via MQTT/TLS, and automatically push real-time student attendance and lab assessment scores into Matrix Cloud LMS.

Connect your ESP32 NodeMCU dev kit to the PN532 RFID NFC reader using the SPI interface according to the wiring pinout below:

Module 2

ESP32 MicroPython Firmware

Upload the following MicroPython code snippet to your ESP32 device. This firmware initializes Wi-Fi, scans for student RFID cards, and publishes JSON payloads to Matrix-IoT Broker.

# matrix_iot_node.py - Matrix-IoT ESP32 MicroPython Client
import network
import ujson
import time
from umqtt.simple import MQTTClient
from machine import Pin, SPI

# 1. Network Configuration
WIFI_SSID = "College_Lab_WiFi"
WIFI_PASS = "LabSecurePass2026"
MQTT_BROKER = "mqtt.matrix-iot.com"
CLIENT_ID = "esp32_lab_station_01"
COLLEGE_TENANT_ID = "meridian_college"

def connect_wifi():
    wlan = network.WLAN(network.STA_IF)
    wlan.active(True)
    if not wlan.isconnected():
        print("Connecting to Wi-Fi...")
        wlan.connect(WIFI_SSID, WIFI_PASS)
        while not wlan.isconnected():
            time.sleep(0.5)
    print("Wi-Fi Connected! IP:", wlan.ifconfig()[0])

# 2. Main Scan & Publish Loop
def publish_attendance(rfid_uid):
    client = MQTTClient(CLIENT_ID, MQTT_BROKER, port=8883, ssl=True)
    client.connect()
    
    payload = ujson.dumps({
        "tenant_id": COLLEGE_TENANT_ID,
        "station_id": CLIENT_ID,
        "rfid_card_uid": rfid_uid,
        "timestamp": time.time(),
        "action": "LAB_CHECK_IN"
    })
    
    topic = "matrix-iot/" + COLLEGE_TENANT_ID + "/attendance"
    client.publish(topic, payload)
    print("Published RFID UID [" + rfid_uid + "] to Matrix Cloud LMS!")
    client.disconnect()

connect_wifi()
# Simulated RFID scan callback
publish_attendance("9A-4F-88-C2")
